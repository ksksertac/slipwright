# Changelog

## 0.2.0

- The work list of a development in a tab, with approve and reject.
- A live event stream: the tree and the open tabs follow the server, the connection comes
  back by itself and replays what it missed, and a gate that opens is announced.
- New project from the editor: source, repository (existing or opened now), language.

## 0.1.0

- Sign in to a Slipwright server; the token is kept in VS Code's secret storage.
- Projects and their developments in the activity bar, with the state of each one and a
  mark on anything waiting for a person.
- Start a development from the editor, and open a project or a development in the browser.
